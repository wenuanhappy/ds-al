## 1. 用户认证与个人信息

基础路径：`/api`

### 1.1 登录
- 接口：`POST /api/login`
- 描述：校验用户名/密码，记录登录日志并升级经验。
- 请求示例 (JSON body):
```json
{
  "username": "user1",
  "password": "password123"
}
```
- 成功响应示例（项目使用 `Result` 统一包装）：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userid": "101",
    "username": "user1"
  }
}
```

### 1.2 注册
- 接口：`POST /api/register`
- 请求示例：同登录体，可包含 `email`、`tel`。
- 响应：布尔值（`true` 成功，`false` 失败）。

### 1.3 获取用户信息
- 接口：`GET /api/me/space?username={username}`
- 返回：`UserBean` 对象（JSON）。

### 1.4 更新用户信息
- 接口：`PUT /api/me/space`（JSON body）
- 请求示例：
```json
{
  "username": "user1",
  "email": "new@example.com",
  "tel": "13900000000",
  "password": "newpassword"
}
```

主要模型：
- `UserBean` 字段（主要）：`id`、`username`、`password`、`email`、`tel`、`level`、`exp`、`createTime`、`updateTime`。

## 2. 好友系统

项目含两套好友接口：新流程（基于缓存的好友申请 + 自动接受）和旧版直接关系接口。

### 2.1 新版（FriendRequestController，base `/api/friends`）
- 发起申请：`POST /api/friends/apply`
  - 请求示例：
```json
{
  "fromId": 101,
  "toId": 102,
  "message": "你好"
}
```
  - 返回 data.status: `applied` / `auto_accepted` / `already_friends`。
- 获取申请列表：`GET /api/friends/requests?userId={id}&page=0&size=20`
  - 返回 `{ total, requests }`。
- 处理申请：`POST /api/friends/respond`
  - 请求示例：
```json
{
  "responderId": 101,
  "requesterId": 102,
  "accept": true
}
```

### 2.2 旧版/直接调用（FriendController）
- 获取好友列表：`GET api/friends?username={username}` → 返回 `List<UserBean>`。
- 添加好友（直接）：`POST api/addFriends?username={username}&friend={friendName}` → 布尔值。
- 删除好友：`POST api/deleteFriends?username={username}&friend={friendName}` → 布尔值。

## 3. 评论系统（CommentController）

基础：`@RequestMapping("/api/comments")`。

主要接口：
- 列表：`GET /api/comments?courseId={cid}&courseType={type}&page=1&pageSize=20&sort=newest&includeReplies=false&replyLimit=3&currentUserId={id}`
  - 返回 `Result<PageResponse<CommentResponseDto>>`。
- 详情：`GET /api/comments/{id}?replies_page=1&replies_pageSize=10&replies_sort=oldest` → `CommentDetailDto`。
- 发布：`POST /api/comments`（`CreateCommentRequest`）
- 编辑：`PUT /api/comments/{id}`（`EditCommentRequest`）
- 删除：`DELETE /api/comments/{id}`（`DeleteCommentRequest`）
- 点赞：`POST /api/comments/{id}/like`（`LikeCommentRequest`）
- 取消点赞：`DELETE /api/comments/{id}/like`（`LikeCommentRequest`）



发布示例：
```json
{
  "userId": 101,
  "username": "alice",
  "courseId": "1001",
  "courseType": "tree",
  "content": "很好！",
  "parentId": null
}
```

成功响应示例：
```json
{
  "code": 200,
  "message": "发布成功",
  "data": {
    "comment": { "id": 123, "content": "很好！", "user": {"id":101,"username":"alice"} },
    "status": "success"
  }
}
```

## 4. 学习记录与登录统计（LearningController / LoginLogController）

LearningController 主要接口：
- `POST /api/me/studyrecord/generatenewrecord` — 请求体包含 `username`、`topicname`，用于新增学习记录并增加经验。
- `POST /api/me/studyrecord/newpractice` — 新练习记录。
- `GET  /api/me/studyrecord/history?username={username}` — 返回 `List<LearningHistory>`。
- `GET  /api/me/studyrecord/Practicehistory?username={username}` — 返回练习记录列表。
- `GET  /api/me/studyrecord/countalgorithm?username=...` — 返回整数。
- `GET  /api/me/studyrecord/countcourse?username=...` — 返回整数。
- `GET  /api/me/studyrecord/getID?username=...` — 返回用户 ID（Integer）。

LoginLogController（登录统计）接口：
- `GET /api/me/studyrecord/lastlogin?username=...`
- `GET /api/me/studyrecord/activedays?username=...`
- `GET /api/me/studyrecord/userlevel?username=...`
- `GET /api/me/studyrecord/userexp?username=...`

## 6. 通用返回结构 & 错误码

项目使用 `edu.sufe.common.Result` 作为统一返回结构（示例）：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": { ... }
}
```

常见错误码（约定）：
- `400` 参数错误
- `401` 未登录/登录状态失效
- `403` 无接口访问权限
- `404` 资源不存在
- `500` 服务器内部错误

## 7. 运行与调试说明

- Java 版本：17
- 使用 Maven Wrapper（仓库包含 `mvnw` / `mvnw.cmd`）

快速构建（Windows PowerShell）：
```powershell
.\mvnw.cmd clean package -DskipTests
```

或 macOS / Linux：
```bash
./mvnw clean package -DskipTests
```

运行：
```bash
java -jar target/_111-0.0.1-SNAPSHOT.jar
```

配置（主要）：编辑 `src/main/resources/application.properties` 或通过环境变量覆盖：
- `DB_URL`（默认：jdbc:mysql://db:3306/ds?...）
- `DB_USERNAME`（默认：root）
- `DB_PASSWORD`（默认：00000000）

Swagger / OpenAPI：
- UI: `http://<host>:<port>/swagger-ui.html`
- JSON: `http://<host>:<port>/api-docs`
