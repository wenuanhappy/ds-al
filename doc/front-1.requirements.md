# 数据结构与算法学习平台 - 需求文档

## 1. 项目概述
本项目是一个基于 Web 的综合性平台，旨在通过交互式可视化、详细的课程内容社交学习功能，帮助用户学习数据结构和算法。系统的目标是将抽象的算法概念转化为直观、可视化的体验。

## 2. 功能需求

### 2.1. 认证模块
系统必须提供安全且用户友好的认证机制。
- **注册**：
  - 用户可以使用用户名、密码、邮箱和手机号创建账户。
  - **验证**：对邮箱格式（正则）、手机号格式（正则）和必填字段进行实时或失焦时的验证。
  - **反馈**：在输入框下方显示清晰的错误信息；通过 Toast 通知提供成功反馈。
  - **安全**：密码输入必须支持显示/隐藏切换。
  - **用户体验**：提交时显示加载状态，防止重复点击。
- **登录**：
  - 使用用户名和密码进行安全登录。

### 2.2. 导航与课程结构
平台应将学习内容组织成逻辑分类。导航系统使用集中式的路由配置。
- **分类**：
  - **线性表**：顺序表、单链表、栈、队列、链式队列。
  - **树**：二叉搜索树 (BST)、AVL 树、霍夫曼树、堆 (小根堆/大根堆)、线索二叉树、二叉树转换。
  - **图**：深度优先遍历 (DFS)、广度优先遍历 (BFS)、Prim 算法、Kruskal 算法、Dijkstra 算法、Floyd 算法、拓扑排序。
  - **排序**：比较排序、堆排序、基数排序。
  - **查找**：查找算法、字符串匹配。
- **课程列表 UI**：使用网格布局展示可用课程，包含图标和标题，便于访问。

### 2.3. 交互式学习与可视化
- **算法可视化**：
  - 每个课程模块必须包含算法的动态可视化演示（例如，展示树如何旋转或排序如何交换元素）。
  - 可视化脚本必须**懒加载**，以确保初始页面加载速度快。只有访问特定路由时，才加载庞大的算法脚本。
- **脚本管理**：
  - 提供全局的 `ScriptLoader` 工具，用于处理可视化资源的预加载和按需加载。

### 2.4. 社交与社区系统
为了营造协作学习环境，系统包含强大的社交功能。
- **好友系统**：
  - **好友列表**：查看已添加的好友，显示头像、等级和经验值。
  - **添加好友**：按用户名搜索用户。发送带有自定义消息的好友请求。
  - **请求管理**：
    - 查看收到的好友请求，并带有徽章计数通知。
    - 同意或拒绝请求。
    - 状态处理：检测用户是否已经是好友或请求是否处于待处理状态。
  - **删除好友**：经确认后从好友列表中移除用户。
- **评论系统**：
  - **讨论**：用户可以在特定课程页面发表评论。
  - **互动**：
    - **点赞**：用户可以点赞有帮助的评论。
    - **编辑/删除**：用户可以管理自己的评论。
    - **乐观 UI**：操作（如点赞）后界面立即更新，仅在服务器请求失败时回滚。
  - **显示**：显示相对时间戳（例如“5分钟前”）和用户头像。

### 2.5. 练习模式
选本练习模块使用内嵌页面，使用vue代码重构所有的练习模块，使其更加合理。

### 2.6. AI 互动
为用户提供智能化的算法学习辅助。
- **多模型支持**：支持切换 **GPT-4V** 和 **Coze** 智能体。
- **多模态交互**：
  - **图片上传**：支持用户上传题目或算法图解进行提问。
  - **粘贴支持**：支持直接从剪贴板粘贴图片发送。
- **配置管理**：支持用户自定义和保存 API Key。
- **角色扮演**：AI 被设定为专业的算法导师，提供结构化的回答（原理、复杂度、代码）。

## 3. 非功能需求

### 3.1. 用户界面 (UI) 与 用户体验 (UX)
- **设计系统**：使用 **Element Plus** 打造一致、专业的外观和感觉。
- **响应式**：布局（特别是网格视图）应适应不同的屏幕尺寸。
- **反馈**：使用 Toast 消息（瞬时通知）进行“成功”、“错误”或“加载中”等操作提示，让用户知情且不阻塞工作流。

### 3.2. 性能与加载 (Performance)
- **构建优化 (Build Optimization)**:
  - **分包策略 (Code Splitting)**: 使用 Vite 的 `manualChunks` 将第三方依赖（Vue核心库、UI组件库、工具库）与业务代码分离，利用浏览器缓存机制减少重复加载。
  - **代码压缩**: 生产环境构建时自动移除 console/debugger，并进行 Terser 代码混淆压缩。
- **资源加载 (Resource Loading)**:
  - **路由懒加载**: 所有路由组件采用 `dynamic import` 方式，实现按需加载，显著降低首屏体积。
  - **算法脚本按需加载**: 针对庞大的可视化算法脚本，实现自定义 `ScriptLoader`，仅在进入特定算法页面时加载对应逻辑。
  - **图片优化**: 静态资源（图片）经过预压缩处理，减少传输流量。
- **组件优化**:
  - **按需引入**: 使用 `unplugin-vue-components` 实现 Element Plus 等组件库的自动按需引入，避免全量打包。

### 3.3. 可靠性
- **错误处理**：优雅地处理网络错误（例如在评论或好友模块中），向用户显示错误信息而不是空白屏幕。

## 4. 技术栈
- **前端框架**：Vue 3 (Composition API)。
- **构建工具**：Vite。
- **UI 组件库**：Element Plus。
- **路由**：Vue Router（带有用于确保认证的导航守卫）。
- **HTTP 客户端**：Axios。
- **图标**：Element Plus Icons / SVG。

## 5. 部署
- **容器化**：支持 Docker（标准 Dockerfile ）。
- **Web 服务器**：配置 Nginx 用于服务构建后的静态资源并处理路由回退 (SPA 支持)。
