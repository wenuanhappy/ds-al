# Docker在本地环境构建
@维护人:470413346@qq.com

## 0. 准备工作
在开始之前，请确保：
1. **本地开发环境**：
- java 17
- maven 3.8+
- nodejs 18+
- mysql 8.0
- Docker version>=25 
- 可以构建docker本地环境（可以魔法上网（下载依赖））

(若无，下文有安装教程)

2. **服务器环境**：
- 已安装 Docker 和 Docker Compose。(Docker version>=25.10.17)
3. **源代码**：
- 项目代码结构组织逻辑如下
    ``` 
    web-project/                         # 项目根目录
    ├── web_data_structure/              # 前端子项目
    │   ├── ...                          # 前端项目代码
    │   ├── Dockerfile                   # 前端dockerfile
    │   ├── .dockerignore
    │   └── nginx.conf                   # nginx配置
    ├── server_data_structure/           # 后端子项目
    │   ├── ...                          # 后端项目代码
    │   ├── Dockerfile                   # 后端dockerfile
    │   ├── .dockerignore
    │   ├── .mvn/                        # mvn依赖
    │   ├── mvnw
    │   ├── mvnw.cmd
    │   └── pom.xml
    ├── docker-compose.yml               # 编排前端、后端、数据库
    └── ds-al.sql                        # 项目sql文件        
    ```

## 1.本地docker部署
> 构建镜像需要魔法上网（或者添加国内镜像源）来下载所需要用到的依赖镜像，否则可能会构建失败。


### 构建步骤

1. 打开终端，进入项目根目录：
```bash
cd web-project
```

2. 执行构建命令（根据docker-compose.yml，会自动构建前端和后端）：
```bash
docker compose build
```

3. 查看docker镜像
```bash
docker images
```
```bash
goose@goose:~$ docker images
                                                        i Info →   U  In Use
IMAGE                          ID             DISK USAGE   CONTENT SIZE   EXTRA  
ds-backend:1.0                 0964c9b7d540       1.06GB          410MB        
ds-frontend:1.0                30fb92c25198        102MB         29.8MB        
mysql:8.0                      0275a35e79c6       1.08GB          247MB 
```
4. 启动docker镜像 后台启动
```bash
docker compose up -d
```
5. 访问docker-compose.yml中暴露的端口
前端页面localhost:9100

#### 2.2.2 导入数据文件

##### 方案一:mysql bash

```sql
-- 创建数据库
crate database ds;
-- use
use ds;
-- 设置root用户的密码
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '00000000';
--  刷新权限
FLUSH PRIVILEGES;
-- 导入文件确定好ds-al.sql的路径
source D:/web-project/ds-al.sql 

-- (可选：云主机不用docker的mysql镜像时可以用) 
-- 对应修改mysql的配置文件/etc/mysql/mysql.conf.d/mysqld.cnf， 确保 bind-address和mysqlx-bind-address 设置为 0.0.0.0 
-- 修改完成需要sudo systemctl restart mysql
-- 修改root用户的被限制的ip范围，改为不限制，及允许所有ip访问
update user set host = '%' where user = 'root';
```

#### 2.3.2 搭建开发环境步骤
1. 使用**IntelliJ IDEA**集成环境
    - 修改数据库连接配置文件
    用IDEA打开project，
    修改 src/main/resources/application.properties
    修改为**自己数据库的配置**（地址、用户、密码）
    - 修改maven配置
    在setting中的Build,Execution,Deployment的Build Tools下修改maven配置，取消勾选Override。
    - 运行程序
    在IDEA中运行 src/main/java/com.example/Application文件

2. 使用**命令行/vscode**开发
    - 修改数据库连接配置文件
        修改 src/main/resources/application.properties
        修改为**自己数据库的配置**（地址、用户、密码）
    - 打开vscode内部终端
    ```bash
    # 进入后端文件夹
    cd web-project/server_data_structure
    # mvn构建
    mvn clean package
    # 或者 mvn构建 跳过test文件夹
    mvn clean package -DskipTests
    # 构建完成以后运行打包好的jar包
    java -jar target/_111-0.0.1-SNAPSHOT.jar
    ```
## 3.docker云部署

### 方案一：本地打包docker镜像上传服务器加载部署（推荐）
适用于服务器docker构建有问题
参考 docker_cloud_deploy.md

### 方案二：服务器直接构建部署
与##1.本地docker部署类似
缺陷：
如果服务器配置较差，构建时间长（2C2G 30M带宽构建过程中，会导致ssh断开，大约2小时完成）

### 方案三：docker仓库上传与拉取
镜像本地完成构建后
Docker push image-name推送镜像到Docker hub
从Docker hub拉取
```bash
# 查看所有镜像
docker images -a

# 需要登录
docker login

docker push [OPTIONS] NAME[:TAG]

docker pull [OPTIONS] NAME[:TAG|@DIGEST]
```
