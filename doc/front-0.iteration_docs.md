# 数据结构可视化平台 - 迭代说明文档

## 1. 迭代概述
本次迭代主要针对旧版 (`vue`)前端进行了全面的重构与升级，形成了新的前端架构 (`web_data_structure`)。核心目标是提升用户体验、增强社交互动性、规范代码架构以及引入更完善的权限与交互机制。

## 2. 架构升级
- **技术栈更新**: 从旧版代码迁移至 **Vue 3 (Composition API)** + **Vite**，提升了构建速度和运行性能。
- **性能优化 (Performance)**:
    - **分包 (SplitChunks)**: 针对 `node_modules` 进行了手动分包配置，将 Vue 相关库、UI 库和工具库（axios）分离，提升缓存命中率。
    - **懒加载 (Lazy Loading)**: 全站路由实现按需加载；特别针对大型算法演示脚本设计了 `ScriptLoader`，大幅减少首屏 JS 体积。
    - **组件优化**: 引入 `unplugin-vue-components` 实现组件按需自动导入，移除未使用的组件代码。
    - **资源压缩**: 构建流程集成 Terser 压缩，并对静态图片资源进行了预处理优化。
- **UI 组件库**: 全面引入 **Element Plus**，替代了原有的样式实现，统一了视觉风格，提升了交互体验。
- **项目结构**: 优化了目录结构，将 API 调用封装、工具类 (Utils) 和 视图 (Views) 进行了更清晰的分离。

## 3. 功能模块迭代

### 3.1 认证模块 (Authentication)
*   **旧版**: 简单的登录/注册表单，缺乏即时验证。
*   **新版**:
    *   **注册增强**: 新增了对邮箱和手机号的正则格式校验，支持实时错误提示。
    *   **安全性**: 密码输入框增加了“显示/隐藏”切换功能。
    *   **反馈**: 引入了 Toast 轻量化提示，注册/登录状态反馈更加直观。
    *   **UI**: 采用了全新的登录/注册背景与卡片式设计，视觉效果更现代。

### 3.2 社交系统 (Social System)
*   **旧版**:
    *   仅支持直接“添加好友”和“删除好友”。
    *   好友列表展示信息较少。
*   **新版 (重大升级)**:
    *   **好友申请机制**: 引入了完整的“申请-审核”流程。用户添加好友时需发送申请，对方同意后方可建立关系。
    *   **申请管理**: 新增“好友申请”标签页，支持查看、同意或拒绝待处理的请求。
    *   **好友展示**: 好友卡片展示头像、等级、经验值等详细信息，支持鼠标悬停动效。
    *   **状态反馈**: 明确区分“已是好友”、“等待通过”等状态。

### 3.3 评论与互动系统 (Interaction)
*   **旧版**: 无此功能。
*   **新版 (新增)**:
    *   **课程评论**: 在算法课程页面新增评论区组件 (`CommentSection`)。
    *   **多级回复**: 支持对评论进行回复，形成讨论串。
    *   **点赞互动**: 支持对评论进行点赞/取消点赞，实时更新计数。
    *   **内容管理**: 用户可以编辑或删除自己发布的评论。

### 3.4 课程与练习 (Course & Practice)
*   **导航**: 优化了路由配置，算法可视化页面支持脚本的**懒加载**，提升首屏速度。
*   **练习模式**: 整合了堆、搜索树、图论等算法的练习模块，路径更加统一。
*   **可视化**: 修复并优化了部分算法演示脚本的加载逻辑和兼容性。

### 3.5 AI 智能助手 (AI Assistant)
*   **旧版**: 仅支持基础的文本对话，单一模型配置。
*   **新版 (增强)**:
    *   **Coze 集成**: 新增 Coze 智能体支持，提供更专业的 RAG（检索增强生成）互动体验。
    *   **多模型切换**: 用户可以在 GPT-4V 和 Coze 之间无缝切换。
    *   **多模态支持**:
        *   **图片上传**: 支持点击按钮上传图片。
        *   **剪贴板粘贴**: 实现了 `paste` 事件监听，支持直接粘贴截图发送给 AI。

## 4. UI/UX 改进
- **交互细节**:
    - 按钮增加了 Loading 状态，防止重复提交。
    - 关键操作 (如删除好友) 增加了二次确认弹窗 (`ElMessageBox`)。
    - 全局统一的字体和配色方案。

## 5. 接口变更 (API)
配合前端功能的迭代，后端 API 进行了相应的扩展（详情见 `api_docs.md`）：
- 新增 `/api/friends/apply` 等申请流接口。
- 新增 `/api/comments` 相关全套 CURD 接口。
- 优化 `/register` 和 `/login` 的参数校验与返回结构。

## 6. 总结
本次迭代将平台从一个简单的演示工具升级为一个具备完整社区属性的学习平台。通过引入 Vue 3 和 Element Plus，系统的可维护性大幅提升；新增的好友申请和评论功能显著增强了用户的留存与互动。
